03
Vue Journée

La vue Journée est l'écran principal. Elle affiche qui travaille où pour le jour sélectionné, organisé par catégorie de site.

Naviguer entre les jours — utilisez la barre de jours en haut (Lun, Mar…). Un point rouge sous un jour indique un conflit. Vous pouvez changer de jour en restant dans la même catégorie.

Écran d'accueil — trois indicateurs en haut (En poste / Absents / Conflits), puis les tuiles cliquables :

🛒 Marchés 🏪 Boutiques 🧑‍🍳 Laboratoire 🎪 Événements

Chaque tuile affiche le nombre de sites ouverts, le nombre de personnes affectées et les avatars de l'équipe. Un badge rouge ⚠ 2 signale des conflits.

Après avoir cliqué sur une catégorie, vous voyez les sites ouverts ce jour avec pour chaque site :

👤
Nom + horaires
Le prénom de chaque employé avec ses horaires (ex: 07:00–14:00)
⋮
Menu action
Cliquez sur ⋮ à droite d'un employé pour le déplacer ou le retirer
+
Ajouter quelqu'un
Bouton "+ Ajouter" en bas de chaque site pour affecter un employé
✅
Absent remplacé : un employé absent apparaît barré en rouge, son remplaçant s'affiche en dessous avec ↳ en vert.
📋
04
Vue Semaine

La vue Semaine donne une vision complète des 7 jours, organisée de la même façon que la vue Journée — par catégorie de site.

Navigation — utilisez les boutons ‹ › dans le header navy pour changer de semaine. Le bouton Auj. revient à la semaine en cours. Le type de semaine (A ou B) est affiché.

Tuiles catégories — cliquez sur Marchés, Boutiques, Laboratoire ou Événements pour voir le détail de la semaine pour cette catégorie.

Vue détail — chaque jour de la semaine est listé verticalement. Pour chaque jour :

📅
Date et site
Le jour avec sa date, le nom du site et les horaires
👤
Employés avec horaires
Chaque personne affectée avec ses horaires individuels
⋮
Actions
Bouton ⋮ pour déplacer ou retirer, bouton + pour ajouter
👥
05
Vue RH

La vue RH remplace l'ancienne vue Équipe. Elle affiche les statistiques mensuelles de chaque employé et les alertes importantes.

Navigation mensuelle — utilisez ‹ › en haut à droite pour changer de mois.

Carte employé — chaque employé est présenté avec :

IndicateurDescription
📅 Jours travaillésNombre de jours effectivement travaillés ce mois / jours prévus
⏱️ HeuresTotal des heures travaillées (calculé depuis les horaires)
🌴 AbsencesNombre de jours d'absence sur jours planifiés, avec détail par type
🏪 Site principalLe site où il/elle travaille le plus ce mois
📅 Prochaine absenceDate et type de la prochaine absence prévue
⚠️
Alertes période d'essai :
🟡 Orange — moins de 30 jours restants
🔴 Rouge — moins de 14 jours restants
🔴 Rouge — période expirée, à confirmer
➕
06
Ajouter au planning

Pour affecter un employé à un site :

1
Accéder au site
Vue Journée ou Semaine → catégorie → site souhaité
2
Cliquer sur + Ajouter
Bouton en bas de la carte du site
3
Choisir l'employé et les horaires
Sélectionnez la personne, ajustez les horaires si besoin
4
Choisir la récurrence
Tous les [jour] de semaine A, B ou les deux — ou ponctuel (une seule date)
💡
Les employés n'ont pas de site fixe dans Planify. Chaque affectation est liée à un jour de la semaine avec une récurrence. Vous pouvez affecter quelqu'un à plusieurs sites différents.
↗️
07
Déplacer & retirer

Pour modifier l'affectation d'un employé, cliquez sur le bouton ⋮ à droite de son nom dans la vue Journée ou Semaine.

Un menu s'ouvre avec deux actions :

ActionPonctuel 📌Permanent 🔁
↗ DéplacerChange le site uniquement pour cette date. Les autres semaines restent intactes.Change le site pour tous les futurs créneaux de ce jour.
✕ RetirerRetire l'employé uniquement ce jour. Les autres semaines restent.Supprime définitivement l'affectation pour ce jour.
⚠️
Lors d'un déplacement, vous pouvez choisir le site cible et modifier les horaires. Les horaires du nouveau site sont pré-remplis automatiquement.
🔄
08
Remplacements

Quand un employé est absent et qu'il était planifié sur un site, un conflit est automatiquement détecté. Planify propose des remplaçants disponibles.

1
Conflit détecté
L'employé absent apparaît barré en rouge avec un badge ⚠️. Un bouton "↳ Programmer un remplacement" apparaît.
2
Choisir le remplaçant
Depuis la vue RH ou en cliquant sur le conflit — Planify propose les employés disponibles (pas absents, pas déjà affectés à ce créneau).
3
Confirmation
Le remplaçant est affiché en vert ↳ sous l'absent barré.
💡
Planify anticipe les conflits sur 6 mois à l'avance. Le badge ⚠ 4 dans le header indique le nombre total de conflits à venir.
🌴
09
Absences

Les absences se déclarent dans ⚙️ → Absences. Chaque employé peut avoir plusieurs absences de types différents.

🌴 CP — Congés payés 🏠 RTT 🤒 Maladie 📅 Sans solde ⭐ Autre

Deux modes de saisie :

ModeUsageExemple
PériodeDates précises de début et finDu 14/07 au 21/07
RécurrentUn jour de la semaine qui revientTous les mercredis — sem. A
✅
Les absences passées ne s'affichent plus dans la liste — seulement le mois en cours et les absences futures. L'historique complet reste accessible dans les Rapports mensuels.
💡
Les absences ne sont comptées dans les rapports que sur les jours où l'employé était planifié. Si Hugo est absent un samedi mais ne travaille jamais le samedi, ce jour ne compte pas.
📝

11
Événements (catering, mariages…)

La catégorie Événements permet de gérer les prestations extérieures : mariages, catering, festivals, etc.

Créer un événement — depuis la tuile 🎪 Événements (vue Journée ou Semaine) → bouton + Créer :

ChampDescription
📛 NomNom de l'événement (ex: Mariage Dupont)
📅 DatesDate de début et de fin (peut durer plusieurs jours)
📍 AdresseLieu de la prestation
💬 CommentaireNotes utiles : contact client, matériel, instructions
👤 PersonnelEmployés affectés avec leurs horaires individuels
💡
Les événements apparaissent dans la vue Journée (tuile violette) et dans la vue Semaine. Vous pouvez les modifier ou les supprimer à tout moment.
⚠️
12
Conflits

Un conflit se produit quand un employé est planifié sur un site mais qu'il est également en absence ce jour-là.

Où voir les conflits :

⚠ 4 dans le header Point rouge sur le jour Carte rouge dans les sites Banner rouge en vue RH

Planify détecte les conflits sur 6 mois à l'avance. Dès qu'une absence est déclarée, tous les conflits correspondants sont identifiés automatiquement.

⚠️
Le filtre horaire est intelligent : si quelqu'un travaille matin (7h–14h) et qu'un autre travaille après-midi (14h–21h) sur le même site, ils ne sont pas en conflit et le remplaçant de l'un ne doit pas forcément être disponible sur les mêmes horaires.
📍

15
Rapports mensuels

Accès : ⚙️ → Rapports mensuels

Pour chaque employé et chaque mois, le rapport affiche :

📅 Jours travaillés ⏱️ Heures totales 🏪 Répartition par site 🌴 Absences par type 📋 Détail des périodes
✅
Les absences ne sont comptées que sur les jours effectivement planifiés. Un jour de repos non planifié ne compte pas comme absence.
🕓
16
Historique

Accès : ⚙️ → Historique

Toutes les actions effectuées dans l'app sont enregistrées avec leur horodatage : affectations, déplacements, absences, décisions sur les demandes de congé…

Les 300 dernières actions sont conservées. L'historique est partagé entre tous les managers.

🔁
17
Semaines A / B

Planify gère un planning en alternance semaine A / semaine B. Le type de la semaine actuelle est affiché dans le header (S.A ou S.B).

Lors de l'affectation d'un employé, vous choisissez :

Semaine A seulement Semaine B seulement Les deux semaines

Un badge 📌 signale une affectation ponctuelle (une date unique). Un badge S.A indique que l'affectation ne s'applique qu'en semaine A.

⏳
18
Période d'essai

Si une date de début est renseignée pour un employé, Planify calcule automatiquement sa période d'essai et affiche des alertes visuelles sur sa carte RH.

DuréeConditionAlerte
J + 60 joursPériode initiale🟡 Orange si < 30j restants
J + 120 joursPériode renouvelée (case ☑️)🔴 Rouge si < 14j restants
—Confirmé en poste (case ☑️)Aucune alerte

Pour modifier : ⚙️ → Employés → [nom] → cocher Période renouvelée ou Confirmé en poste

✅
Dès qu'un employé est Confirmé en poste, l'alerte disparaît définitivement de la vue RH.
